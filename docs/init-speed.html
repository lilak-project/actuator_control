SMC JXC91 · 원점복귀 파라미터

Init 속도를 바꾸는 방법

Init(원점복귀)이 너무 빠를 때, 무엇을 어디서 바꿔야 하는가.

원점복귀 속도는 ORIG speed 파라미터이며, ACT Controller를 USB로 직접 연결해야만 바꿀 수 있습니다.

Actuator Control 웹 UI로는 불가능합니다. EtherNet/IP에 파라미터 오브젝트가 없어서 읽지도 쓰지도 못합니다 — 소프트웨어의 한계가 아니라 컨트롤러의 구조입니다.

먼저 확인할 것

파라미터를 건드리기 전에, 정말 속도가 바뀐 것인지부터 가려야 합니다. 같은 설정으로도 체감 속도가 크게 달라질 수 있습니다.

원점복귀는 스테이지가 서 있던 자리에서 기계적 끝단까지 이동합니다 (§11.1). 가감속은 ORIG ACC/DEC로 정해지는 사다리꼴 프로파일입니다. 따라서:

  • 짧은 구간 — 가속 램프가 끝나기 전에 도착합니다. ORIG speed에 도달하지 못하므로 느려 보입니다.
  • 긴 구간 — 최고 속도까지 가속해 그 속도로 주행합니다. 훨씬 빨라 보입니다.

즉 스테이지를 멀리 두고 Init을 누르면, 파라미터가 그대로여도 예전보다 빠르고 거칠게 움직입니다.

30초 진단

전원이 살아 있고 SETON이 켜져 있다면 — 원점 근처 스텝으로 Move한 다음 Init을 눌러 보세요. 예전처럼 얌전하면 파라미터는 그대로이고 거리 문제입니다.

왜 웹 UI로는 못 바꾸는가

추정이 아니라 매뉴얼과 코드로 확인된 사실입니다.

근거내용출처
EtherNet/IP 오브젝트 SMC 전용 오브젝트는 Step Data Object (Class 67h), Instance 1–64, Attribute 100 하나뿐. I/O는 Assembly Class 04h. 파라미터 오브젝트는 문서화돼 있지 않습니다. §4.3, §4.4
Init이 하는 일 SETUP 비트를 세우는 것이 전부입니다. 속도를 지정하는 필드가 명령에 없습니다. §11.1
출력맵의 수치 지령 17워드가 전부 0으로 고정 송신됩니다. 세 세대의 드라이버 코드가 모두 동일합니다. jxc91.py
파라미터 접근 경로 ACT Controller는 COM 포트로만 통신합니다. 이더넷 경로가 없습니다. ACT §5.1

변경 절차

순서가 중요합니다. 업로드 없이 다운로드하면 화면의 빈 값이 컨트롤러에 덮어씌워집니다.

  1. USB 케이블로 연결

    JXC-W2A-C 케이블로 PC와 컨트롤러를 잇습니다. USB 드라이버는 SMC 코리아 다운로드 페이지에 있습니다.

  2. ACT Controller를 Normal mode로 실행

    Easy mode에는 파라미터 창이 없습니다. Normal mode에서만 파라미터를 다룰 수 있습니다. 연결이 안 되면 Action → System → Setting에서 COM 포트를 확인하세요.

  3. Parameter 창에서 Upload

    컨트롤러에 지금 들어 있는 값을 먼저 읽어옵니다. 이 단계를 건너뛰지 마세요. 현재 값을 Save로 파일에 백업해 두면 되돌릴 수 있습니다.

  4. ORIG speed 를 낮춤

    Return to origin 파라미터 그룹에 있습니다. 허용 범위는 컨트롤러가 아니라 액추에이터 기종이 정합니다 — 카탈로그의 최소·최대 속도를 확인하세요.

  5. Download

    컨트롤러에 기록됩니다. 매뉴얼 Write 열이 ■이므로 즉시 반영되고 재시작이 필요 없습니다. 값은 EEPROM에 남습니다.

  6. 안전한 위치에서 Init 검증

    스테이지 주변을 비우고 한 번 실행해 확인합니다. 값이 액추에이터 허용 범위를 벗어나면 알람 049 Parameter value is wrong이 뜹니다.

손댈 수 있는 원점복귀 파라미터

속도만이 답은 아닙니다. 원점 센서가 달려 있다면 ORIG mode가 더 근본적인 해결입니다.

파라미터효과범위
ORIG speed 원점을 찾아가는 속도. 직접적인 해결책. 액추에이터별
ORIG ACC/DEC 원점 동작 중 가감속. 급출발·급정지를 완화합니다. 액추에이터별
ORIG mode 1. Pushing origin [Stop] — 기계적 끝단까지 밀고 들어감 (기본)
2. Limit switch origin [Sensor] — 원점 센서로 잡음. 끝단에 부딪히지 않습니다.		 1–2
ORIG sensor 원점 센서 사용 설정. 0 비활성 / 1 N.O. / 2 N.C. 0–2
ORIG limit 원점을 확정할 때 밀어붙이는 힘. 액추에이터별
ORIG direction 원점복귀 방향. 1 CW / 2 CCW. 1–2

ORIG time과 Creep speed는 이 컨트롤러에서 고정값이라 바꿀 수 없습니다.

막히지 않습니다

기본 파라미터 Para protect는 1이든 2든 원점복귀 파라미터를 포함합니다. 보호 설정 때문에 편집이 막힐 일은 없습니다 (§10.2).

Init 자체는 건너뛸 수 없습니다

"그냥 Init을 안 쓰면 되지 않나"는 아쉽게도 불가능합니다.

이유내용출처
인코더 Incremental A/B phase, 800 pulse/rotation. 절대치가 아니라 전원을 끄면 위치 정보가 사라집니다. §4 사양
전원 투입 절차 전원 → SVON → SVRE → SETUP → SETON §13
미확립 시 이동 알람 099 Drive is ON when SETON is OFF §15.2
다만 한 번이면 됩니다

상태표에 따르면 SV Off를 해도 SETON은 유지됩니다 (§9). 컨트롤러 24V를 끊지 않는 한 원점은 남아 있습니다.

따라서 SV Off·Disconnect·서버 재시작·5분 유휴 자동 SV Off 어느 것도 재Init을 유발하지 않습니다. 다시 쓸 때는 SV On만 누르면 됩니다.

주의

기계적 끝단까지 이동합니다

기본 ORIG mode 1에서 원점복귀는 스테이지를 끝단에 의도적으로 부딪히게 합니다 (§11.1). 경로에 시료·검출기·케이블이 없는지 확인한 뒤 실행하세요.

모터 구동 전원(M24V)이 끊긴 상태로 SETUP을 걸면 컨트롤러가 원점을 잘못 인식합니다 (§14).

동시 접속 금지

ACT Controller로 작업하는 동안에는 Actuator Control 서버를 내려 두세요. 같은 컨트롤러에 두 클라이언트가 동시에 쓰는 것을 컨트롤러가 중재해 주지 않습니다.
